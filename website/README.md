To view the html website:
    1. Either download the ZIP of the project or clone it.
    2. Unzip the downloaded project
    3. Open up the Doxygen application
    4. Click on File (located up top) and select Open
    5. Go to the project's folder and open Doxyfile
    6. Then, go to Run in Doxygen, press "Run doxygen" and then "Show HTML output"

Or run "doxygen Doxyfile" in the project's folder and open website/html/index.html.
The output in website/html and website/latex is generated and is not kept in Git.
